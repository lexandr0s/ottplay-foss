# Complete manual translations

Ten English guides have complete editions in the 24 documentation languages
listed in [`manual-languages.json`](../manual-languages.json). Each translation
keeps the procedures, commands, identifiers and recorded results of its English
source; it is a translation of the documented revision, not a separate claim
about released behaviour. See [complete manual translations](../manual-translations.md)
for the review and digest procedure that keeps them in step.

The English editions live in the parent directory; the `.<lang>` files below
are the translated copies.
